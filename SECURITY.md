# Security Policy

## Supported Versions

Security fixes are provided for the latest CamBatch release.

## Reporting a Vulnerability

Please do not include sensitive project files in a public issue. Contact the maintainer privately through the contact method listed on the GitHub profile, and include the CamBatch version, Blender version, operating system, impact, and reproduction steps.

CamBatch does not use the network, run external programs, or install Python dependencies. Its file access is limited to creating the chosen output folder and writing rendered images there.
